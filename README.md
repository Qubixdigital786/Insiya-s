# Insiya & Ali Asghar - Wedding Invitation Card Editor

Interactive, offline-ready wedding invitation card editor for **Insiya & Ali Asghar**.

## Features
- **Card 1 (Cover)**: Personalize guest names and details on the door card with serif/calligraphy font choices and alignment options.
- **Card 2 (Main Wedding Invite)**: Set Gents and Ladies member counts inside `G ( )` and `L ( )`.
- **Card 3 (Program Functions)**: Customize member counts for all 4 wedding events:
  - Mehendi-Mosalu (14th Jan 2027)
  - Awta-Jata (15th Jan 2027)
  - Dubalo (16th Jan 2027)
  - Vevan Navshi (15th Jan 2027)
- **High-Resolution Exports**: Download high-res PNGs, individual PDFs, complete 3-page consolidated PDF, or a ZIP package of all cards.
- **Royal Emerald & Antique Gold Theme**: Styled with emerald teal, antique gold gradients, plum accents, and a Dark/Light mode toggle.
